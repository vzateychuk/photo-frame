# Photo Frame MVP

Веб-фоторамка для Raspberry Pi. Показывает случайные фотографии из локальной папки в браузере TV-приставки.

## Стек
- **Backend**: Node.js, Fastify, TypeScript, Zod (валидация конфига), Sharp (обработка фото).
- **Frontend**: Vite, TypeScript.

## Быстрый старт

1. **Настройка окружения**:
   Скопируйте `.env.example` в `.env` и укажите путь к папке с фотографиями:
   ```env
   PHOTOS_DIR=/path/to/your/photos
   PORT=3000
   HOST=0.0.0.0
   NODE_ENV=dev
   ```

2. **Установка зависимостей**:
   ```bash
   npm install
   ```

3. **Запуск в режиме разработки**:
   ```bash
   npm run dev
   ```
   (Запускает одновременно бэкенд с hot-reload и фронтенд-сервер Vite).

4. **Сборка и запуск**:
   ```bash
   npm run build
   npm start
   ```

## Структура проекта
- `src/back` — серверная часть (API, обработка изображений, работа с ФС).
- `src/front` — клиентская часть (интерфейс слайд-шоу).
- `docs/concept` — техническое задание и дизайн системы.

## Особенности MVP
- Рекурсивное чтение папок.
- Автоматический ресайз под разрешение экрана приставки.
- Плавная смена кадров с предзагрузкой следующего изображения.
- Поддержка JPEG и PNG.
