# Photo Frame MVP

Веб-фоторамка для Raspberry Pi. Показывает случайные фотографии из локальной папки в браузере TV-приставки.

## Стек
- **Backend**: Node.js, Fastify, TypeScript, Zod (валидация конфига), Sharp (обработка фото).
- **Frontend**: Vite, TypeScript (Vanilla, без фреймворков).

## Быстрый старт

1. **Настройка окружения**:
   Скопируйте `.env.example` в `.env` и укажите путь к папке с фотографиями:
   ```env
   PHOTOS_DIR=/path/to/your/photos
   PORT=3000
   HOST=0.0.0.0
   NODE_ENV=development
   ```

2. **Установка зависимостей**:
   ```bash
   npm install
   ```

3. **Запуск в режиме разработки**:
   ```bash
   npm run dev
   ```
   (Запускает одновременно бэкенд с hot-reload и фронтенд-сервер Vite).

4. **Сборка и запуск**:
   ```bash
   npm run build
   npm start
   ```

## API Endpoints

| Метод | Путь | Описание |
|-------|------|----------|
| `GET` | `/health` | Проверка здоровья сервиса |
| `GET` | `/api/play/next` | Вернуть ID следующего фото (`{id: "uuid"}`) |
| `GET` | `/api/photos/:id?w=1920&h=1080` | Бинарный JPEG стрим с ресайзом |

### Параметры `/api/photos/:id`
- `w` — ширина (100–3840, default 1920)
- `h` — высота (100–2160, default 1080)

## Переменные окружения

| Переменная | Описание | Обязательна | Default |
|------------|----------|-------------|---------|
| `NODE_ENV` | `development` \| `production` \| `test` | Нет | `development` |
| `PORT` | Порт сервера | Нет | `3000` |
| `HOST` | Бинд адрес | Нет | `0.0.0.0` |
| `PHOTOS_DIR` | Путь к папке с фото | **Да** | — |
| `LOG_LEVEL` | Уровень логов pino | Нет | `info` |

## Структура проекта
- `src/back` — серверная часть (API, обработка изображений, работа с ФС).
- `src/front` — клиентская часть (интерфейс слайд-шоу).
- `docs/concept` — техническое задание и дизайн системы.
- `docs/ARCHITECTURE.md` — **подробная архитектура для разработчика** (pipeline, тесты, Docker, дебаг).

## Особенности MVP
- Рекурсивное чтение папок.
- Автоматический ресайз под разрешение экрана приставки с учётом EXIF-ориентации.
- Плавная смена кадров с предзагрузкой следующего изображения (два слоя, crossfade).
- Поддержка JPEG и PNG.
- Потоковая отдача изображений без сохранения на диск.

## Docker
```bash
docker compose up -d
```
Требует `docker-compose.yml` с монтированием фото в `/data/photos:ro` и переменной `PHOTOS_DIR=/data/photos`.
